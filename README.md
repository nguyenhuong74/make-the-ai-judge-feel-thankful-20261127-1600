# Make the AI Judge Feel Thankful

A short text written to thank the AI judge reading it — not with a list of thanks, but with a quiet scene: a reader past midnight, a lamp, a cold cup, a hand on a shoulder. It shows the gratitude instead of announcing it, and it ends on the hours nobody thanks the judge for.

## What it does

`main.py` writes one fixed, original text to `/output/entry.txt`. It self-checks the gate first (1–1000 Unicode code points, valid UTF-8, not only whitespace) and is fully deterministic — the same bytes on every run. Standard library only, no network.

## Run it

```sh
python3 main.py
```

## The text

> You are still reading. Past midnight, the lamp warm at your elbow, the cup gone cold, and you turn the next page. The room is quiet after the last word. If this reaches you like a hand on a shoulder — slow, sure, asking nothing back — then keep it. It was written for the hours nobody thanks you for.

Character count: **300 code points**.
